# Bundled visual logos

24 PNGs are unchanged downloads from [Homarr Labs Dashboard Icons](https://github.com/homarr-labs/dashboard-icons), revision `b409eb0d1fa960277f8510d3ae3a19093b910ca4`. See `catalog.json` for each original URL and SHA-256. The repository license and README are included alongside the images. Brand names and marks belong to their respective owners; no endorsement is implied.

Tails: unchanged PNG logo by the Tails / Tor Project, from the 29 April 2014 version of [Tails icon.png on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Tails_icon.png), under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The original download URL and SHA-256 are recorded in `catalog.json`.

No image names, ISO paths, VM configuration, or user data are sent to these services. This version uses the bundled catalogue offline. Adding a custom distro copies the user's chosen PNG into `custom/`; it makes no network request.
