# L2: завершение доступной локальной приёмки

30 октября 2026. Ветка codex/l2-diagnostics-completion, база 9ae988b.
Чеклист: **92/98 — 93,9%**, прирост **26 пунктов** относительно 66/98.
Часть функций была реализована раньше; здесь закончены недостающие детали
и принята их проверка. Это не 26 новых независимых функций.

## Изменения

- В параметрах стенда добавлена «Диагностика общих сетей»: выбор сети,
  VM/NIC/MAC, сохранённые NAT, фактические порты и подключения, счётчики,
  время и последние события. Готовность помощника, подключение QEMU и
  непроверенная связь гостевых ОС показаны отдельно.
- Чтение асинхронное, обновление по кнопке, закрытие не выполняет stop/start.
  Named pipe не удерживает глобальную блокировку операций стендов.
- Helper хранит кольцо из 32 фиксированных событий с UTC/категорией/индексом,
  без кадров и их содержимого. Переполнение очереди не создаёт событие на
  каждый отброшенный кадр. Добавлены категории ошибок запуска/порта/доступа.
- Редактор показывает MAC/модель/другие NAT, явно сохраняет видимость пропавшего
  NIC и блокирует неявную потерю такого участника при сохранении.
- Исправлена утечка названия сети в тексте событий support-отчёта; дополнительно
  маскируются адреса IP/MAC и названия NIC. Данные кадров в отчёт не попадают.
- JSON null/array/повреждённый manifest теперь отвергаются понятной protocol-ошибкой
  до запуска probe. После очистки неудачного старта причина ошибки остаётся видна.
- Обновлены FAQ, руководство, обзор безопасности и отдельный план выпуска.

## Проверки

- Полный tools/test.py --gui через компактный профиль: **301 unit**, **13 GUI-наборов**.
  StandsTests: **62 проверки**, включая отмену после удаления сети, отсутствующий
  NIC, большие счётчики, закрытие до ответа и читаемое окно в размере 800×600.
- switch-core --qemu: **21 сценарий/набор**; дополнительно в native CoreTests
  проверены UTC и ограничение кольца событий 32 записями.
- switch-service: **10 сценариев**, manifest/Unicode/ownership/active lease,
  самостоятельный выход и занятый порт.
- switch-integration: **8 сценариев**; в повторном backend overview проверяет
  существующие соединения ещё до явной сверки. Только свои qcow2/paused TCG.
- Изолированный app ZIP: **75 файлов**, manifest/source/hash audit без замечаний.
  InstallTests сохраняет данные и pending journal при установке/обновлении;
  UpdateTests проверяет rollback/сохранение стендов и active-operation guard.
- Полный audit.py --staged выполняется через временный индекс/objects под build;
  реальный индекс не меняется. Отчёты/receipts/скриншоты остаются в ignored build.

4. **12.5:** медленный/аварийный реальный QEMU-гость и измерение пропускной

   согласованию; пользовательские VM в этой работе не запускались.

   и spoofing. Ping/подключение QEMU не считаются доказательством.

Коммит, push, релиз, смена версии, установка в пользовательское приложение и
чужие VM/диски не выполнялись. Для выпуска использовать L2-SWITCH-RELEASE-PLAN.md.
