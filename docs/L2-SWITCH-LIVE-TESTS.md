# Следующий этап: загруженные гости

Исторический план подготовки. Препятствие снято предоставленным Alpine 3.24.3;
успешный прогон и актуальный прогресс: L2-SWITCH-LIVE-RESULTS.md.

30 октября 2026, ветка codex/l2-live-guest-tests. Итог чеклиста остаётся
**92/98**: новых галочек без гостевых доказательств не поставлено.

Пользователь попросил приступить к оставшимся испытаниям. Подготовлен отдельный
opt-in tools/test_switch_live.py: три собственных загруженных Linux/TCG-гостя,
192 МБ/1 CPU каждый, без дисков, NAT, внешней сети и пользовательских конфигураций.
Это специальное испытание реального гостевого обмена, а не обычный paused --qemu
регрессионный набор; он не включён автоматически в tools/test.py.

## Что фактически сделано

- Проверены официальный каталог Alpine virt и формат составного initramfs.
- Подготовлен разбор ISO в памяти и собственный init-overlay для serial console;
  оригинальный образ не меняется. SHA256 проверяется до запуска любого процесса.
- Helper используется в штатном guarded-режиме с PID/FILETIME. Очистка работает
  только с захваченными Popen-процессами самого теста; пользовательские VM не ищутся.
- Предусмотрены направленные IPv4/IPv6 ping и ARP-neighbors, отключение третьего
  гостя и проверка связи оставшихся. Полный приём broadcast на каждом получателе
  и замер throughput ещё нужно добавить после проверки доступных гостевых applets.
- Пять offline unit-тестов построения CPIO/границ/оптического формата/проверки
  checksum/обязательного --live прошли. Boot самого стенда ещё не выполнен.

## Точное препятствие

Получение официального тестового ISO из среды выполнения не удалось:
Python HTTPS — WinError 10060, затем системный curl по IPv4 — timeout 28.
Ни образ, ни опубликованная SHA256 не получены. Web-документация читается другим
каналом, это не доказывает возможность скачать файл в локальный workspace.
Ограничения не обходились; пользовательские ISO/диски не использовались.
Ни один загруженный гость в этой попытке не стартовал.

После появления отдельно полученного официального ISO и опубликованной checksum:

```
python tools/test_switch_live.py --live --iso build/live-net/alpine-virt-3.22.7-x86_64.iso --sha256 PUBLISHED_SHA256
```

PUBLISHED_SHA256 заменить реальным 64-значным значением официального источника.
Не указывать checksum, просто вычисленную с неизвестного образа. Требуется
предварительная локальная сборка tools/build.py. ISO/логи/созданный initramfs/
results.json остаются под ignored build/live-net. Kernel/module/appet совместимость
прототипа не подтверждена; не считать его готовым E2E до настоящего прогона.
Даже успешный текущий прототип не закрывает весь 12.4: в results явно отмечен
незавершённый broadcast receive. Для 12.5 нужен отдельный throughput/slow-peer этап.

## Проверенная среда

Windows 11 build 26300, QEMU 11.1.1, обычные права, один экран 1920×1080,
системный DPI 96 (100%). Локальная запись: build/live-net/environment.json.
Это одна точка матрицы, не проверка Windows 10, других DPI, мониторов или антивирусов.

Источники:
[официальные Alpine образы/checksums](https://dl-cdn.alpinelinux.org/alpine/v3.22/releases/x86_64/),
[формат initramfs ядра Linux](https://docs.kernel.org/driver-api/early-userspace/buffer-format.html).
