- 77 Python unit-тестов; native GUI, 38 проверок обновлятора, реальный QMP/PNG на временной TCG-VM — пройдены.

- Аудит Git-индекса: 91 файл, замечаний нет. Пакет приложения: 48 файлов, состав совпадает с исходниками, замечаний нет.
- Публичный GitHub API проверен сетевым кодом обновлятора; опубликованный пакет будет проверен после загрузки.
- Не проверены: чистый другой компьютер, установка QEMU через UAC и полноценная загрузка гостевых ОС. EXE не подписан сертификатом издателя.
