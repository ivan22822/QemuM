# Чеклист: локальный L2-коммутатор стендов QemuM

Статус: интегрированы модель, план запуска и жизненный цикл. Галочку ставить только
после реализации и проверки. План не меняет установленный QEMU, существующие VM
или текущие незакоммиченные изменения MCAST. Отдельный релиз не предполагается
без запроса пользователя.

Цель: три и более VM одного стенда обмениваются Ethernet-кадрами через
локальный коммутатор и стандартный socket backend QEMU на Windows.
Дополнительный NAT-адаптер может оставаться у каждой VM. IP/DHCP задаются
в гостях или отдельным сервером. Применение к idle scan зависит от IP ID
zombie, прохождения подменённых пакетов и конфигурации гостей.

## Прогресс ядра (29 октября 2026)

Созданы src/switch/LocalSwitch.cs и tools/test_local_switch.py. Это отдельный
экспериментальный тестовый помощник; в запуск пользовательских стендов он пока
не подключён. Слушает только loopback, 2–64 порта, до 64 кадров в очереди
получателя, размер кадра 14–65535 байт, до 4096 MAC с aging 300 секунд.

Пройдено 8 интеграционных проверок: дробление TCP-заголовка и тела, broadcast,
learned unicast, multicast, отсутствие эха, отдельные сети, порядок кадров,
отказ при oversized-заголовке, повторное подключение и создание трёх собственных
diskless paused TCG QEMU с подключением к коммутатору. Проверка кадров выполнена
синтетическими клиентами; QMP/подключение QEMU не доказывают передачу внутри ОС.

Следующий обязательный этап — проверка владельца QEMU для каждого подключения,
управляющий протокол, журнал и независимый жизненный цикл помощника. До этого
ядро не включается в production-пакет и не предлагается для пользовательских VM.
Далее — схемы стендов, предпросмотр/запуск, интерфейс и восстановление.
