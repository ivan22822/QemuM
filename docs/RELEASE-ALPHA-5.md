# QemuM 0.1.0-alpha.5 · Альфа

Добавлены пользовательские стенды: выберите VM, настройте внутренние связи
и последовательность запуска. Тумблер переключает обычную библиотеку и папки
стендов. Список остаётся слева, параметры — справа; ширина списка регулируется.

- Последовательный запуск, продолжение, отмена будущих этапов и выключение
  в обратном порядке. Работающие VM при отмене остаются работать.
- Предварительный план с проверкой конфигураций, ресурсов и занятых портов.
  Проверяется фактически установленное TCP-соединение между процессами QEMU;
  один ответ QMP больше не считается подтверждением сетевой связи.
- История, явная сверка после перезапуска, дублирование ссылок, удаление папки
  без удаления VM и добровольный отчёт с предпросмотром.
- Описания встроенных WHPX/TCG-профилей и сохраняемое описание своих профилей.
  Сохранены профили из сборок alpha.4, включая WHPX qemu64 + SSE4/POPCNT.
- Единые тёмные поля и прокрутка, дополнительные ответы FAQ.
- В установщик, launcher, встроенный обновлятор и Refresh включён актуальный
  код обновлений. Активная операция стенда блокирует обновление и откат.

**Обновление:** закройте менеджер после завершения операций и откройте
«Обновления». Alpha.5 имеет приоритет над всеми сборками alpha.4.
Если ранний обновлятор не обнаруживает выпуск, используйте `QemuM-Refresh.exe`
из этого релиза. Новую установку выполняйте через Setup в пустую папку.
Пользовательские данные и образы отделены от файлов программы.

**Ограничения альфы:** внутренние связи не назначают IP/DHCP в гостевых ОС
и не создают общий коммутатор. Готовность QEMU/TCP не гарантирует загрузку ОС.
Снимок одной VM не является согласованным снимком стенда. Сохранение RAM
через WHPX по-прежнему ограничено стандартным QEMU.

Автоматически проверены модели до 64 участников, интерфейс с 501 VM/100 стендами
и настоящие приостановленные TCG-стенды из 1–3 VM. Реальный IP-обмен гостевых ОС,
64 одновременно исполняющиеся VM, смешанные ускорители и несколько физических
мониторов/DPI остаются вне подтверждённой матрицы этого выпуска.

Подробности: [руководство по стендам](https://github.com/ivan22822/QemuM/blob/codex/stands-execution/docs/STANDS.md).
