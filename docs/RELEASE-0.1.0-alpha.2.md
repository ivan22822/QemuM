# QemuM 0.1.0 Alpha 2

## Изменения

- Установщик показывает отдельный прогресс Python, QEMU и приложения.
  При загрузке доступны процент и объём в МБ, при распаковке — процент файлов.
  Проверки и внешний установщик QEMU показывают неопределённый прогресс:
  их внутренний процент недоступен.
- Установщик и окно обновлений используют общие цвета, тёмную шапку,
  скруглённые кнопки и голубые индикаторы в стиле «Полярная ночь».
- Новое окно обновлений входит в пакет приложения. После обновления через
  прежний загрузчик кнопка «Обновления» открывает новый интерфейс.
- Добавлены выбор, создание и запуск основных дисков VDI. Драйвер QEMU
  задаётся явно, автоматической конвертации нет. Старые qcow2 продолжают
  работать с прежним форматом.

## Установка и обновление

Для новой установки скачай EXE Setup этого выпуска. Пользователям Alpha 1:
открой «Обновления», проверь версию, закрой основное окно менеджера и установи
обновление. Затем открой приложение прежним ярлыком QemuM.
Настройки, ISO, диски и пользовательские данные не заменяются пакетом.

VDI выбирается в параметрах VM или при её создании. Для нового диска укажи
расширение .vdi. Основной диск подключается через VirtIO, как и qcow2:
гостевая Windows должна иметь нужный драйвер. Полная загрузка образа,
созданного в VirtualBox, может потребовать настройки контроллера гостевой ОС.

Внутренние снимки VDI не поддерживаются. Для снимков нужны записываемые
диски qcow2; менеджер отклоняет операцию до изменения диска.

## Проверки

Проверяются unit/GUI-сценарии, распаковка и запуск релизного пакета,
QMP на временном qcow2 и создание/подключение временного VDI с остановленным CPU.
Полная загрузка пользовательской ОС и установка QEMU через UAC на другом
компьютере этими проверками не подтверждаются. EXE не подписан сертификатом.
