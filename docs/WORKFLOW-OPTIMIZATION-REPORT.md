# Оптимизация процесса: выполнено

30 октября 2026. Только локальные изменения, без коммита/публикации/установки.

В `WORKFLOW.md` закреплены 25 конкретных приёмов. Созданы краткий контекст,
карта подсистем, карточка задачи и локальная точка входа QEMUM-WORKSPACE
в корне рабочего зеркала. В AGENTS.md активного checkout сохранены правила:
точечное чтение, отсутствие рутинных статусов, короткий финал, сохранение
dirty-изменений и обязательных проверок.

Добавлен tools/workflow.py: готовые профили unit/stands/network/snapshots/L2/GUI,
однострочный итог, полные локальные журналы, receipt с командой/временем/кодом
и source SHA256, проверка устаревания, отказ PASS при изменении исходников,
явное включение native-проверок. Результаты не кэшируются для пропуска тестов.
Поиск отпечатка ограничен исходниками; private data и build не читаются.
Вывод контекста поддерживает кириллицу, Git status ограничен первыми 12 строками.

Проверки: четыре новых unit-теста runner (выбор профиля, изменения исходников,
ошибка процесса, тайм-аут/отсутствующий exe), полный unit-набор из 293 тестов,
ручной smoke context/last и отказ native-профиля без явного флага.
Изменение файла во время первого полного запуска было обнаружено: несмотря на
293 успешных теста результат не помечен PASS. Для итогового receipt выполнен
новый прогон после завершения правок. Функциональный GUI/backend QemuM в этой
задаче не менялся; повторный GUI/QEMU прогон для документов/runner не требуется.

Корневой AGENTS.md зеркала доступен только для чтения, он оставлен без изменений.
Маршрутизация записана отдельным QEMUM-WORKSPACE.md, а исполняемые инструкции —
в AGENTS.md рабочего checkout. Синхронизированные sources не затронуты.

Ветка codex/workflow-efficiency создана отдельно; незакоммиченные L2/MCAST
сохранены при переключении. Процент экономии токенов не измерялся.
Автоматическая смена модели/тарифа, создание чатов и обновление установки
не выполнялись. Предпочтения действуют в контексте этого checkout; прямой
новый запрос пользователя имеет приоритет.
