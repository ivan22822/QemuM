# Диагностика установки у другого пользователя

Передай два файла из tools/ вместе:

- QemuM-Diagnose.ps1
- Run-QemuM-Diagnostics.cmd

Другу нужно распаковать оба файла в одну папку и дважды нажать
Run-QemuM-Diagnostics.cmd, пока установка находится на проблемном этапе.
Повышение прав не требуется.

Скрипт наблюдает активность примерно 15 секунд; полный сбор может занять дольше.
На рабочем столе появится папка QemuM-Diagnostics с ZIP и распакованным отчётом.
Перед отправкой нужно просмотреть содержимое. Дополнительно сообщить точный этап,
версию установщика, длительность ожидания и приложить скриншот.

Если выбрана нестандартная папка установки, открой PowerShell в папке со скриптом:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\QemuM-Diagnose.ps1" -InstallPath "D:\Programs\QemuM Alpha"

Чтобы выбрать место отчёта:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\QemuM-Diagnose.ps1" -InstallPath "D:\Programs\QemuM Alpha" -OutputDirectory ".\Reports"

ExecutionPolicy Bypass действует только для этого запуска PowerShell; постоянная
политика системы не меняется. На управляемом компьютере ограничения организации
могут запрещать запуск — это не требуется обходить.

Скрипт собирает версии Windows/PowerShell, свободное место, два замера процессов
установщиков и их потомков, размеры/время изменения известных файлов, контрольную
сумму стабильного скачанного установщика QEMU и недавние события Windows,
упоминающие QEMU. Ошибки доступа также записываются в отчёт.

Командные строки процессов, содержимое VM-конфигураций, диски, ISO, скриншоты
и живые логи не собираются. Имена пользователей в стандартных путях маскируются.
Текст событий может содержать другие личные данные — проверь перед отправкой.
Скрипт ничего не скачивает и не отправляет, не запускает QEMU,
не завершает процессы и не меняет установку.

Совпадение хеша проверяется с QEMU 20260811, закреплённым в Alpha 1/2.
Несовпадение может означать частичный файл или другую версию, а не обязательно
повреждение. Отсутствие активности не доказывает зависание.
