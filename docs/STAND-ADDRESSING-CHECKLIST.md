# Адресация и разделение экрана стенда

Запрос: автоматические IPv4/IPv6, закрепление адресов, ручной режим; сеть целиком
в отдельном окне, запуск отдельно, главное окно без общей прокрутки.

- [x] Убрать схему, TCP, MCAST и список общих сетей с главного экрана.
- [x] Разделить обзор, запуск, журнал и обслуживание.
- [x] Убрать внешнюю прокрутку главной карточки стенда.
- [x] Сохранить сетевую схему и диагностику в отдельном сетевом окне.
- [ ] Перенести редактор очередности из сетевого окна на страницу запуска.
- [ ] Проверить компоновку при стандартном размере и разных DPI.
- [ ] Добавить версионированные настройки адресации общей сети с миграцией старых стендов.
- [ ] Режимы: вручную в госте, автоматически, резервирование по MAC.
- [ ] Проверять IPv4-подсеть, пул DHCP, IPv6 ULA /64 и пересечения адресов.
- [ ] Исключать адрес службы, broadcast и зарезервированные адреса из пула.
- [ ] Проверять повторяющиеся MAC/IP и попадание резервирования в подсеть.
- [ ] Стабильно хранить назначения отдельно от конфигураций гостевых ОС.
- [ ] Реализовать DHCPv4 DISCOVER/OFFER/REQUEST/ACK/NAK, renew/rebind/release.
- [ ] Проверять границы Ethernet/IP/UDP/DHCP, длины и контрольные суммы.
- [ ] Добавить ARP-ответы только для собственного адреса службы.
- [ ] Реализовать IPv6 RA/RS, SLAAC и NDP для собственного адреса службы.
- [ ] Не объявлять шлюз по умолчанию в изолированной сети: сохранить NAT-интерфейс гостя.
- [ ] Объяснить различие SLAAC и закреплённого IPv6; не обещать резервирование SLAAC по MAC.
- [ ] Выбрать и реализовать DHCPv6-резервирование либо явно обозначить ручной постоянный IPv6.
- [ ] Ограничить скорость запросов, память и размер таблицы аренд.
- [ ] Привязать службу к конкретной общей сети и её проверенному владельцу.
- [ ] Запускать и восстанавливать службу вместе с коммутатором; учитывать блокировку обновления.
- [ ] Сохранять отказ при конфликте параметров работающей сети.
- [ ] Добавить переключатель и поля в сетевой редактор, показывать результат в диагностике.
- [ ] Добавить FAQ: автоматическая настройка гостя, отсутствие интернета у изолированной сети.
- [ ] Проверить выдачу, обновление и резервирование адресов на временных гостях.
- [ ] Проверить несколько изолированных стендов, рестарт контроллера и падение службы.
- [ ] Проверить сохранность конфигураций VM, маршрута NAT и отказ на испорченных пакетах.
