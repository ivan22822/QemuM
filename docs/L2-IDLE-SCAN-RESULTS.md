# Idle scan: реальная проверка с отрицательным результатом

30 октября 2026, codex/l2-idle-scan-test. Только три собственных Alpine-гостя
из предыдущего проверенного ISO, изолированный loopback-коммутатор, без NAT
и внешних целей. Пользовательские VM/FreeBSD не запускались.

Это собственный ограниченный TCP/IPID эксперимент, не запуск Nmap: Nmap
в окружении не найден. Добавлен только явный флаг --idle-scan к opt-in live-тесту;
обычные тесты или UI сканирование не запускают. Адреса фиксированы тестовым
сегментом; произвольного CLI target нет. Четвёртый TCP endpoint принадлежит
Python probe-процессу и авторизуется обычным native PID/FILETIME.

## Наблюдения

- Шесть SYN/ACK-проб zombie дали IP ID **0, 0, 0, 0, 0, 0**.
- Подменённый SYN с IP zombie достиг target: получен SYN/ACK с правильным ACK.
  Для этого отдельного доказательства временно изменён ARP только своего target;
  перед слепыми пробами восстановлен реальный MAC zombie.
- Повторены попытки на известном открытом 7777 и закрытом 7778 портах:

| Порт | IP ID до/после | Δ IP ID | Дополнительный zombie RST |
| --- | --- | --- | --- |
| 7777 | 0 / 0 | 0 | 1 |
| 7778 | 0 / 0 | 0 | 0 |
| 7777 повтор | 0 / 0 | 0 | 1 |
| 7778 повтор | 0 / 0 | 0 | 0 |

RST посчитаны диагностически внутри собственного zombie через /proc/net/snmp.
Этот доступ не является слепым каналом idle scan и не используется для заявления
об успешном определении портов. Он подтверждает, что ожидаемая реакция гостей
и spoof-доставка работают, хотя IP ID её не раскрывает.

## Вывод

Этот Alpine Linux **не подходит как zombie для классического IPID idle scan**.
Открытый/закрытый порты по IP ID здесь неразличимы; выдавать их классификацию
было бы неверно. В этой конфигурации препятствие — поведение IP ID гостя,
а не блокировка подмены источника локальным коммутатором.
Другой кандидат должен пройти проверку общего последовательного счётчика;
название ОС само по себе пригодность не гарантирует.

12.7 оставлен открытым до положительной проверки с подходящим zombie.
Общий прогресс остаётся 94/98. Новых продуктовых функций/публикаций нет.

Два unit-теста проверяют Ethernet/IP/TCP поля, контрольные суммы и отсечение
неподходящих кадров. Реальный эксперимент завершён; собственные гости закрыты,
helper завершился после выхода авторизованного probe-процесса. Обход проверки
владельца для остановки helper не добавлялся. Полные результаты и serial-логи
остаются локально под ignored build/live-net.

Методика и требование глобального IP ID:
[официальное описание Nmap idle scan](https://nmap.org/book/idlescan.html).
