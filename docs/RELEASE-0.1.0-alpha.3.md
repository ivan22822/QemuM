# QemuM 0.1.0 — Альфа 3

Добавлены редактируемые и пользовательские профили ускорения.

- В параметрах VM рядом с профилем запуска появилась кнопка «Настроить…».
- Можно указать WHPX/TCG, модель и опции CPU, опции ускорителя, сохранить
  настройки для следующих машин, создать и удалить свой профиль.
- Добавлен готовый профиль «WHPX · совместимый» с `kernel-irqchip=off` и CPU `host`.
- Параметры выбранного профиля сохраняются в VM. Удаление профиля из каталога
  и обновление приложения не лишают ранее настроенные VM этих параметров.
- Проверка перед запуском и VM Doctor используют сохранённые настройки.
  Успешная проверка создания VM не гарантирует загрузку конкретной гостевой ОС.

Для обновления существующей альфы: «Обновления» → «Проверить» →
«Установить обновление». Пользовательские данные остаются в `data/`.
Установщик предназначен для новой установки в пустую папку.

После настройки профиля нажми «Сохранить профиль», «Выбрать» и сохрани VM.
Изменения действуют при следующем запуске. «Авто» по-прежнему проверяет
обычный WHPX, затем TCG; его алгоритм не редактируется.

Проверены каталог, конкурентное сохранение, копии профилей в VM,
совпадение параметров проверки и запуска, интерфейс и пакет обновления.
Совместимость каждого сочетания CPU/опций с каждым компьютером не проверялась.
Исполняемые файлы не подписаны.
