# QemuM Alpha

Скачай `QemuM-0.1.0-alpha.2-Setup.exe` из Releases проекта и запусти его.
Нужны Windows 10/11 x64 и интернет. Установщик создаёт отдельную папку
`%LocalAppData%\QemuM Alpha`, скачивает закреплённый Python 3.14.8 и использует
найденный QEMU. Если QEMU отсутствует, скачивает сборку 20260811 с
qemu.weilnetz.de, проверяет SHA-512 и запрашивает права для установки QEMU.
Сам менеджер запускается без прав администратора.

Установщик не содержит твоих VM. Добавь ISO или виртуальный диск через
«Новая машина». Рекомендуется использовать отдельные учебные диски. Для WHPX
нужны виртуализация в прошивке и Windows Hypervisor Platform. Если аппаратное
ускорение недоступно, выбери «Авто» или TCG в параметрах VM; TCG медленнее.

## Обновления

Открывай приложение через ярлык «QemuM Alpha» в меню «Пуск» или `QemuM.exe`
в папке установки. Кнопка «Обновления» проверяет GitHub Releases.
Перед установкой обновления закрой менеджер. Работающие VM продолжают работу.
Предыдущая версия сохраняется; при завершении новой версии до готовности
загрузчик возвращает предыдущую. Обновления менеджера не обновляют Python/QEMU.

После полной переработки приложения обновление продолжит работать, если новая
версия соблюдает [протокол запуска и обновлений](UPDATE-PROTOCOL.md).

## Если что-то пошло не так

1. Открой «Помощь / отчёт», выбери VM и опиши действия, ожидание и результат.
2. Отметь только нужные категории. Для ошибки запуска обычно достаточно
   живого лога и параметров запуска. Скриншот доступен, когда VM работает и
   QMP поддерживает PNG. Диагностика отчёта пассивная; расширенная проверка
   ускорителей выполняется отдельно через VM Doctor.
3. Сохрани ZIP в выбранную папку, открой его и проверь содержимое. Маскирование
   скрывает известные пути и типовые секреты, но не гарантирует полную анонимность.
   Скриншоты не маскируются. Удали личные данные перед публикацией.
4. Нажми «Открыть GitHub Issues», найди похожую проблему или создай новую.
   Вставь описание и перетащи проверенный ZIP в сообщение.

GitHub Issues публичные. Программа сама ничего не отправляет и не требует
GitHub-токен. Если менеджер вообще не открывается, создай issue через браузер:
https://github.com/ivan22822/QemuM/issues/new/choose

## Ограничения первой альфы

- EXE не подписан сертификатом издателя; Windows может показывать предупреждение.
- Обновление требует закрыть менеджер; оно не завершает процессы принудительно.
- Состояние пользовательских данных не откатывается вместе с кодом.
- Существующие личные конфигурации из старой установки автоматически не импортируются.
- ZIP приложения — пакет обновления, не отдельный установщик.
- При прерванной первой установке файлы сохраняются для диагностики; повторная
  установка требует новой пустой папки.
- Проверка на чистом компьютере и полноценная загрузка гостевых ОС должны быть
  отмечены отдельно в заметках выпуска; автоматические тесты этого не доказывают.

VDI: можно выбрать существующий диск или создать новый с расширением .vdi.
Снимки доступны только для qcow2. Подключение основного диска — VirtIO; гостю нужен соответствующий драйвер.
