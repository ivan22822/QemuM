# QemuM Alpha

Скачай `QemuM-0.1.0-alpha.5-Setup.exe` из Releases проекта и запусти его.

## Стенды

Включи «Режим стендов» в библиотеке, создай папку и выбери существующие VM.
Список слева и параметры справа сохраняют привычное расположение.
В карточке стенда доступны состав, соединения, порядок, подтверждаемый план
запуска, остановка и сверка после сбоя. IP/DHCP внутри гостей настраиваются
вручную. Подробности и ограничения — в `STANDS.md` из пакета приложения.

Alpha.5 обновляет все компоненты обновлятора и имеет приоритет над сборками
alpha.4. Если ранняя установка не видит выпуск, запусти `QemuM-Refresh.exe`
из нового релиза. Перед обновлением закрой менеджер и заверши операции.

При создании VM с установкой ISO на новый диск кнопка «Обзор…» у виртуального
диска выбирает папку. Имя нового файла формируется из короткого имени VM
с расширением `.qcow2` (если имя пока пустое — `disk.qcow2`). Поле остаётся
редактируемым: можно изменить имя или выбрать `.vdi` для нового диска VDI.
В режиме существующего диска «Обзор…» выбирает уже готовый файл.

## Удаление из библиотеки

В окне удаления выбери «Убрать из списка · файлы сохранить», чтобы удалить
только JSON записи VM. Диски, ISO, логи и прежние копии останутся на месте.
Другой режим удаляет проверенный список личных файлов VM; общие диски и ISO
сохраняются. Перед подтверждением проверь список файлов и введи точное имя VM.
Для обоих режимов VM должна быть выключена. Копия параметров включена
по умолчанию; её можно отключить флажком «Сохранить копию параметров».

## Общий буфер обмена и захват клавиш

В справке Extra args найди «Буфер и клавиши Windows»: там есть готовый пример
GTK + qemu-vdagent. В гостевой системе нужен работающий совместимый агент,
а сборка QEMU должна поддерживать GTK и clipboard. Один `-display` в Extra args
заменяет SDL по умолчанию. Не дублируй устройства и ID из уже имеющихся аргументов.
Чтобы вернуть захваченные клавиши хосту, переключи захват через `Ctrl+Alt+G`.
Подробности: [клавиши QEMU](https://www.qemu.org/docs/master/system/keys.html).

## Профили ускорения

В «Параметры VM» рядом с профилем запуска нажми **«Настроить…»**.
Можно изменить встроенные WHPX/TCG, создать свой профиль на основе выбранного
и удалить пользовательский профиль. Укажи название, ускоритель, модель CPU
и опции ускорителя через запятую. Например, для совместимого WHPX:
CPU `host`, опции `kernel-irqchip=off`. Не добавляй `-accel` или `-cpu`.
Поддерживаемые опции зависят от QEMU; неподдерживаемые значения покажут ошибку
при проверке перед запуском. «Авто» сохраняет встроенный алгоритм WHPX → TCG.

Нажми **«Сохранить профиль»**, затем **«Выбрать»** и сохрани параметры VM.
Каталог общий для следующих VM и хранится отдельно от версии приложения.
У каждой VM сохраняется собственная копия выбранных настроек: правка или
удаление профиля из каталога не меняет ранее настроенные машины.
Чтобы применить новые настройки к существующей VM, выбери профиль заново
через «Настроить…» и сохрани VM. Запущенная VM применит их при следующем запуске.
Нужны Windows 10/11 x64 и интернет. Установщик создаёт отдельную папку
`%LocalAppData%\QemuM Alpha`, скачивает закреплённый Python 3.14.8 и использует
найденный QEMU. Если QEMU отсутствует, скачивает сборку 20260811 с
qemu.weilnetz.de, проверяет SHA-512 и запрашивает права для установки QEMU.
Сам менеджер запускается без прав администратора.

Установщик не содержит твоих VM. Добавь ISO или виртуальный диск через
«Новая машина». Рекомендуется использовать отдельные учебные диски. Для WHPX
нужны виртуализация в прошивке и Windows Hypervisor Platform. Если аппаратное
ускорение недоступно, выбери «Авто» или TCG в параметрах VM; TCG медленнее.

## Обновления

Открывай приложение через ярлык «QemuM Alpha» в меню «Пуск» или `QemuM.exe`
в папке установки. Кнопка «Обновления» проверяет GitHub Releases.
Перед установкой обновления закрой менеджер. Работающие VM продолжают работу.
Предыдущая версия сохраняется; при завершении новой версии до готовности
загрузчик возвращает предыдущую. Обновления менеджера не обновляют Python/QEMU.

После полной переработки приложения обновление продолжит работать, если новая
версия соблюдает [протокол запуска и обновлений](UPDATE-PROTOCOL.md).

## Если что-то пошло не так

1. Открой «Помощь / отчёт», выбери VM и опиши действия, ожидание и результат.
2. Отметь только нужные категории. Для ошибки запуска обычно достаточно
   живого лога и параметров запуска. Скриншот доступен, когда VM работает и
   QMP поддерживает PNG. Диагностика отчёта пассивная; расширенная проверка
   ускорителей выполняется отдельно через VM Doctor.
3. Сохрани ZIP в выбранную папку, открой его и проверь содержимое. Маскирование
   скрывает известные пути и типовые секреты, но не гарантирует полную анонимность.
   Скриншоты не маскируются. Удали личные данные перед публикацией.
4. Нажми «Открыть GitHub Issues», найди похожую проблему или создай новую.
   Вставь описание и перетащи проверенный ZIP в сообщение.

GitHub Issues публичные. Программа сама ничего не отправляет и не требует
GitHub-токен. Если менеджер вообще не открывается, создай issue через браузер:
https://github.com/ivan22822/QemuM/issues/new/choose

## Ограничения первой альфы

- EXE не подписан сертификатом издателя; Windows может показывать предупреждение.
- Обновление требует закрыть менеджер; оно не завершает процессы принудительно.
- Состояние пользовательских данных не откатывается вместе с кодом.
- Существующие личные конфигурации из старой установки автоматически не импортируются.
- ZIP приложения — пакет обновления, не отдельный установщик.
- При прерванной первой установке файлы сохраняются для диагностики; повторная
  установка требует новой пустой папки.
- Проверка на чистом компьютере и полноценная загрузка гостевых ОС должны быть
  отмечены отдельно в заметках выпуска; автоматические тесты этого не доказывают.

VDI: можно выбрать существующий диск или создать новый с расширением .vdi.
Внутренние снимки доступны для qcow2; для одного VDI поддерживается приватная внешняя цепочка qcow2. Подключение основного диска — VirtIO; гостю нужен соответствующий драйвер.

## Снимки в alpha.4

Если у тебя уже стоит локальная alpha.4, опубликованный пакет того же номера
можно поставить без перехода на alpha.5. Скачай `QemuM-Refresh.exe` из этого
релиза, дождись окончания дисковых операций и закрой менеджер. Запусти утилиту
и нажми «Переустановить текущую версию». Она скачает пакет с GitHub, проверит
хеши, сохранит прежние файлы программы и оставит данные VM на месте. Номер
останется alpha.4. Обычный установщик поверх существующей папки для этого не нужен.

Открой VM → «Снимки дисков». Создание/откат, защита, независимый ZIP,
расписание и диагностика описаны в [SNAPSHOTS.md](SNAPSHOTS.md).
До обновления дождись завершения операций снимков. При неопределённом результате
не удаляй журналы и служебные папки: открой «Незавершённые операции…».
