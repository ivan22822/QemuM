# QemuM 0.1.0-alpha.4 · Альфа

Уже установлена локальная alpha.4? Скачай `QemuM-Refresh.exe` из вложений,
закрой менеджер после завершения операций дисков, запусти утилиту и выбери
«Переустановить текущую версию». Она получает пакет с GitHub и проверяет хеши.
Номер остаётся alpha.4, прежние файлы программы сохраняются, данные VM не заменяются.

Большое обновление управления снимками: внутренние онлайн/офлайн-группы qcow2,
страховочные точки и восстановление параметров, приватные внешние ветви,
независимый ZIP-экспорт, расписание, журнал и безопасная отмена на доступных этапах.

Добавлен встроенный FAQ: «Помощь / отчёт» → «FAQ · как пользоваться QemuM».
39 вопросов, поиск по вопросам и ответам и фильтр тем, без интернета.

Исправлено падение каталога снимков при null в необязательных настройках профиля
и метаданных формата. Улучшены отступы, высота полей, читаемость подробностей
и состояния пустого/недоступного списка. Включены ранее подготовленные исправления
меню, прокрутки, панели VM и удаления регистрации без удаления дисков.

Ограничения: RAM-снимки только в проверенной конфигурации TCG на паузе;
стандартный WHPX не поддержан. Собственная сборка QEMU не устанавливается.
Commit/rebase/merge только планируются. Проверка Guest Agent с тестовым агентом
не заменяет испытания реальных гостевых файловых систем. Старые образы после
офлайн-операций сохраняются и расходуют дополнительное место. Снимок не заменяет
независимую резервную копию. Настоящие DPI нескольких мониторов и физическое
отключение питания не аттестованы. Подробности: docs/SNAPSHOTS.md.

Скачай Setup.exe для новой установки. Для установленной альфы используй
«Обновления». Пакет приложения ZIP предназначен для обновлятора. Дождись
завершения дисковых операций и закрой менеджер. Пользовательские данные
хранятся отдельно от кода; обновлятор не завершает процессы QEMU принудительно.
