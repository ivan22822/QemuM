22 октября 2026. Ветка `codex/snapshot-offline-workflow`.
Последнее указание пользователя: закончить работу, сначала обновить локальную
программу до alpha.4; GitHub-релиз отложить.

## Выполнено

К существующим формам подключены независимый ZIP-экспорт выбранной точки либо
текущих дисков, асинхронное выполнение с реальными этапами/байтами и безопасной
отменой, коды ошибок и добровольный журнал снимков в отчёте. Стилистику «Полярная
ночь» сохранили. Экспорт доступен и без существующих снимков. Это отдельные
развёрнутые образы, без RAM и runtime; файлы назначения не перезаписываются.

Исходные образы удерживаются нативными Windows-дескрипторами. qemu-img получает
только приватные копии. Для внешних цепочек копируются необходимые зависимости
и разворачиваются в независимый результат. Структура/формат/размер проверяются
всегда, полное сравнение и SHA-256 — по выбору. Проверка/упаковка отменяемы,
публикация ZIP выполняется после проверки, потерянный ответ сверяется по
принадлежности, размеру и времени изменения результата.

Журналы не вытесняют аварийные данные: максимум 512 шагов, при 2000 операциях
приём новых операций останавливается; обновление существующего намерения и
обычный запуск VM этим лимитом не блокируются. Отчёт ограничен 2 МБ, не содержит
полных планов/параметров/RAM/образов. Секреты в сохраняемых параметрах запрещены,
известные пути маскируются в диагностике по выбору пользователя.

Исправлены чтение ANSI/Unicode-вывода Windows QEMU, проверка заявленного формата,
кратковременная блокировка публикации JSON Windows и запуск QGA-защитника без
создания pycache в неизменяемой папке версии.

## Проверки

- 189 модульных тестов, включая занятые/подменённые файлы, устаревшие планы,
  неизвестные процессы/форматы, ENOSPC, тайм-аут qemu-img, дубли ID и журнал.
- Нативные окна: обновлятор, установщик, редактор, меню, поля, оформление,
  отчёты, профили и снимки. Tab/Escape, состояния VM, 200 записей, длинные
  названия/описания и программное масштабирование 125/150/200%.
- Настоящие кнопка создания и план подтверждения → локальный RPC → qemu-img;
  офлайн-восстановление без запуска и с отдельным запуском собственного QEMU
  на паузе, удаление точного UUID и сохранение выделения.
- Измерение UI во время создания: 538 событий таймера, максимальный интервал
  232 мс в контрольном прогоне. Это измерение данной тестовой среды, не SLA.
- QEMU 11.1.1: собственные 1/2/3 диска, байтовая проверка создания/отката,
  отказ первого/среднего/последнего шага публикации create/delete/restore,
  частичные приватные группы, отмена и восстановление после сбоя.
- Два независимых процесса службы: взаимное исключение и отказ устаревшего
  второго плана. Источники после отказа/отмены сохраняют точные байты.
- Экспорт qcow2/raw/VDI и зарегистрированных внешних цепочек; независимость
  результата и открытие экспортированной копии отдельной новой TCG VM на паузе.
- Три разрешённых конфигурации RAM TCG, фактические RAM/CPU/дисковые данные,
  обновление копии backend, перезапуск QEMU и отказ несовместимой сборки.
- Независимый QGA-защитник: настоящий процесс и TCP, проверка владельца,
  гибель родителя и подтверждённый thaw с частным тестовым агентом.
- Обновление пакета alpha.3 → alpha.4 в отдельной временной установке:
  тестовые регистрация, диск и незавершённый журнал неизменны; новая версия
  обнаруживает блокировку; замена frontend по update protocol 1 работает.
- Аудит исходников и состава пакета: секретов/личных путей/пользовательских
  файлов не найдено. Генерируемые пакеты, тестовые данные и локальные отчёты
  находятся только в игнорируемом `build/`.

Контрольная производительность: пустая группа из трёх дисков — 1,50 с,
заполненная — 1,47 с, чтение 15 групп — 0,21 с, 12 последовательных созданий —
18,00 с. После записи 4 МиБ каждый qcow2 вырос примерно на 4,26 МБ.
Диски теста имеют виртуальный размер 8 МиБ: эти цифры не переносятся на большие
образы. Дополнительные сведения — `build/test-results/snapshot-performance.json`.

## Честные границы проверки

Реальные DPI Windows на нескольких мониторах и гостевые ext4/NTFS с установленным
QGA не проверены. RAM проверена на подготовленном собственном остановленном
TCG-госте; тестовый QGA не заменяет настоящий guest filesystem freeze/thaw.
Физический обрыв питания не воспроизводился. WHPX RAM запрещён по фактическому
ответу QEMU; commit/rebase/merge по-прежнему только планируются. При потере
исходного процесса во время неопределённого RAM-восстановления автоматическая
компенсация не заявляется; запуск блокируется до отдельной проверки.

Рабочие копии и прежние образы сохраняются, автоматического удаления аварийных
активов нет. Снимок не является независимой резервной копией.

## Передача

Локальная alpha.4 фактически активирована через штатный Stage/Activate. Alpha.3
сохранена как previous. Все 38 файлов пользовательских данных сохранили
идентичность, размер и время изменения, JSON дополнительно проверены SHA-256.

изменения; содержимое образов при обновлении не читалось и не записывалось.
Установленный manifest проверен, штатный установленный backend сообщает alpha.4
и читает все 4 VM. После чтения конфигурации повторно сверены. Копия JSON-настроек
и квитанции находятся в игнорируемом `build/local-alpha4-*/`; итог —
`build/test-results/local-alpha4-update.json`. Программа не запускала гостевые VM.

Публикация GitHub, коммит/push и слияние main на этом завершающем этапе не
выполнялись; выпуск отложен по последнему указанию пользователя. Оригинальный
