# Самопроверка качества и безопасности L2

30 октября 2026. Это обзор кода и автоматические проверки, не независимый аудит.

| Поверхность | Контроль |
| --- | --- |
| Вход Ethernet | Loopback, отдельный порт участника; framing 14–65535 до выделения тела; finite partial read |
| Ресурсы | 64 порта, 64 queued frames/получателя, 4096 MAC/aging, frame/byte rate limits |
| Локальный владелец | Native обратная TCP-пара/PID/FILETIME; чужой клиент не заменяет соединённого владельца |
| Управление | Named pipe с ACL пользователя/deny network; проверка server PID/run/protocol/пути/хэша |
| Жизненный цикл | Intent перед spawn, атомарный журнал, неизвестная идентичность блокирует автоматические действия |
| Остановка | Quit при живом/неизвестном owner отвергается; нет kill существующего помощника по одному PID |
| Обновление | Открытая active lease живёт независимо от GUI/backend и блокирует замену |
| Конфигурации | Overlay в памяти, revision/hash/ownership перед стартом; независимый NAT сохраняется |
| GUI | Только читающий overview, async ожидание без глобального job lock; close не вызывает stop |
| Диагностика | 32 фиксированных события, тип/время/индекс; payload/MAC/произвольные данные кадров не сохраняются |
| Отчёт | Allowlist определений/операций, псевдонимы VM/NIC/сетей, маскирование путей/IP/MAC |

В ходе обзора исправлены:

- Имя общей сети попадало в текст события отчёта после анонимизации definition.
  Теперь очищаются и свободные строки событий, включая адреса и NIC.
- Запрос helper pipe в overview удерживал глобальную блокировку операций.
  Теперь сетевое ожидание вынесено из guard; unit проверяет параллельный захват.
- Повреждённый manifest с JSON null/array давал техническое исключение.
  Теперь возвращается категория protocol до запуска probe.
- После неудачного старта и очистки пустого record терялась причина ошибки сети.
  Overview сохраняет категорию последней операции без повторного запуска.

Проверки в tests/unit/test_stand_diagnostics.py, tests/gui/StandsTests.cs,
tests/switch/CoreTests.cs и tools/test_switch_{service,stands,frames,guard}.py.
Состав тестов и фактический итог фиксируются в отчёте текущего этапа.

Новых внешних библиотек/вендорского кода нет: собственный C#, .NET Framework,
Python standard library; тесты вызывают уже установленный QEMU. Зависимость QEMU
не включается новым кодом и её лицензирование поставки здесь не меняется.
Никакой проверки происхождения всей Windows/.NET/QEMU или чужих зависимостей
этот обзор не доказывает.

Остаточные границы: процесс того же пользователя/администратор может менять
его файлы и состояние; SHA256 manifest не подпись и не криптографический канал.
Коммутатор не firewall/VLAN isolation/router; переполнение приводит к потерям.
Сетевые циклы нескольких NIC не устраняются STP. Гость с неверным MAC/IP может
нарушить работу собственного сегмента. IP/DHCP/маршруты/firewall — внутри гостей.
Реальные ОС, высокая нагрузка, антивирусы и разные физические DPI ещё требуют
соответствующих испытаний; успешный unit/paused TCG их не заменяет.
