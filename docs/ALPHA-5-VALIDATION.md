# Alpha.5: состав и проверка выпуска

Выпуск объединяет стенды с ранее опубликованными CPU-профилями alpha.4 build 4,
описаниями профилей и исправлениями оформления. Исходные рабочие каталоги
предыдущих задач сохранены. Версия приложения/backend/support — 0.1.0-alpha.5,
номер сборки начального выпуска — 0.

## Проверки исходников

- `tools/test.py --gui`: 256 unit-тестов и native GUI-набор.
- `GuiTests`: обычный режим VM, отдельный временный paused TCG гость,
  сохранение настроек и новая тёмная прокрутка.
- `StandsTests`: 37 проверок папок, выбора, редакторов, отсутствующей VM,
  отмены, копирования и предпросмотра отчёта.
- `StandsScaleTests`: 10 проверок на 501 VM / 100 стендах, фокус,
  клавиатура и синтетическое масштабирование; один физический экран.
- `tools/test_stands.py --qemu`: 1/2/3 paused TCG VM, два стенда,
  установленные TCP-соединения QEMU, перезапуск backend и неизменность JSON.
- `tools/test_stand_faults.py --qemu`: занятый порт, неустановленное соединение
  при живом QMP, принудительное завершение backend, явная сверка без автозапуска.

## Обязательное обновление обновлятора

- Setup, корневой `QemuM.exe`, встроенный `QemuM.Update.exe` и Refresh
  собираются из актуальных Launcher/UpdateCore/BootstrapUI.
- `tools/audit_release.py` сравнивает байты встроенного обновлятора
  с новым launcher, исходники с ZIP, манифест, хеши и состав пакета.
- InstallTests читает ресурсы настоящего Setup и проверяет точные хеши
  встроенных app.zip и QemuM.exe.
- Новая версия обновлятора при обновлении берёт bootstrap из проверенного
  манифеста пакета; пакет без bootstrap сохраняет прежний protocol-1 launcher.
- Замена bootstrap проверяет закреплённый хеш и сохраняет прежние байты.
- Активный стенд блокирует подготовку, активацию, переустановку и откат.
- UpdateTests проверяет канал, legacy feed, порядок сборок, отказ понижения,
  неверный хеш, running.lock, откат и сохранность определений/журналов стендов.

## Изолированная матрица установки

`tools/test_release.py` использует закреплённый официальный embedded Python
с проверкой SHA-256. Проверены три отдельных каталога под ignored build:
чистая установка, переход с публичной первоначальной alpha.4 с её launcher,
переход с alpha.4 build 2 с её launcher. Проверяются готовность frontend,
сохранение регистрации VM, байтов диска-маркера и незавершённого журнала,
обнаружение будущего патча той же версии и замена frontend на другой язык.
Настоящие пользовательские установки, VM и их файлы не затрагиваются.

У раннего launcher может сохраняться старый код. Для таких установок
поставляется новый Refresh; наличие новой версии приложения не выдаётся
за автоматически проверенную замену каждого ранее установленного launcher.

Проверка публичного скачивания артефактов и канала выполняется после публикации;
её квитанция сохраняется отдельно в ignored build/release, без изменения тега.
До публикации локальная сборка не объявляется доступной через GitHub.

## Оставшиеся аппаратные испытания

Чеклист стендов: 184/189 (97.4%). Открыты физические DPI/несколько мониторов,
64 одновременно исполняющиеся реальные VM, IP-обмен установленных гостевых
ОС и смешанные ускорители. Автоматизация до 64 участников — модель процессов,
а испытания QEMU используют только отдельные приостановленные TCG-гости.
Программный код не меняет настройки ресурсов Windows для прохождения тестов.
