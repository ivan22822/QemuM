# QemuM 0.1.0-alpha.7 · build 1

Обновление интерфейса и отзывчивости для Windows x64.

- Плавное открытие и закрытие диалогов, непрерывное размытие фона и неподвижная компоновка во время чтения данных.
- Повтор анимации состояния при выборе другой VM; исправлена ошибка отрисовки промежуточного статуса NO QMP.
- Исправлены размеры кнопок, выравнивание текста и скругления в окнах машин, стендов и снимков.
- Встроенный шрифт Unbounded и офлайн-логотипы PNG; исправлены приоритет PNG и обновление миниатюр.
- Уменьшена работа при построении настроек: профили загружаются асинхронно, справка создаётся при первом открытии.
- Карточка снимка пересчитывает высоту при выборе записи; увеличен шрифт и сохранено место для обычного описания без прокрутки.

Обновление распространяется как сборка 1 существующей alpha.7 через штатный обновлятор. Форматы VM и механизм запуска QEMU сохранены.
