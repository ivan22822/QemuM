| Параметры VM | Вместе со снимком не сохраняются | CPU, сеть, Extra args остаются текущими |
| VDI | Внутренние снимки запрещены | Поддержка самого диска VDI не равна поддержке его снимков |
| Создание офлайн | Не реализовано в пользовательском сценарии | Доступная кнопка не должна обещать рабочую операцию |
| Удаление снимков | Не реализовано в интерфейсе | Нельзя обещать очистку занимаемого места |
| Guest Agent | Заморозка файловых систем не используется | Нет гарантии согласованности приложений |
| Восстановление после сбоя менеджера | Постоянного журнала операции нет | Страховочный снимок и журнал — разные механизмы |

## 30. Рекомендуемый порядок работ и критерии перехода

| Этап | Состав | Критерий завершения |
|---|---|---|
| A. Уточнение базы | Аудит, возможности, идентификация дисков, матрица поддержки | Ограничения описаны; неизвестные сценарии не показаны как поддерживаемые |
| B. Надёжный фундамент | Общий сервис, блокировки, планы, каталог, журнал, идемпотентность | Отказы и неопределённые результаты не приводят к слепому повтору или запуску |
| C. Управление qcow2 | Создание онлайн/офлайн, названия, просмотр, удаление | Полный цикл на собственных тестовых образах; проверены отказы нескольких дисков |
| D. Надёжный откат | Страховочные группы, компенсация, аварийное восстановление | После прерываний состояние определяется и небезопасный запуск заблокирован |
| E. Параметры VM | Версионированный config snapshot и выбор режима восстановления | Диски и конфигурация не оказываются в случайно смешанном состоянии |
| F. Guest Agent | Sync/freeze/thaw с журналом и ограничением времени | Нет оставленного замороженным гостя в проверенных сценариях отказа |
| G. Дополнительные форматы | Внешние qcow2-слои, VDI-base, зависимости | Исходная база не меняется; цепочка проверена при создании, откате и удалении |
| H. Обслуживание | Защита, расписание, лимиты, независимый экспорт | Автоочистка не удаляет необходимые зависимости и аварийные страховки |
| I. RAM и устройства | Полное состояние только для проверенных сочетаний | Согласованное возобновление подтверждено; несовместимые режимы явно отключены |

Не блокировать исправление очевидной ошибки кнопок до завершения всех поздних
этапов. Но новые мутации дисков не считать готовыми без требуемого фундамента
из этапа B и проверок отказа для соответствующей операции.
