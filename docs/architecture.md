# Границы исходников и рабочей установки

GUI запускает Python-службу скрытым дочерним процессом и общается через JSON-строки в stdin/stdout. Окна QEMU принадлежат гостевым VM и продолжают работать после закрытия менеджера. Python-модули используют стандартную библиотеку; GUI — системный .NET Framework.

| Компонент | Ответственность |
| --- | --- |
| `VMManager.cs` | Окна, запуск службы, запросы и отображение состояния |
| `GuiLaunchSettings.cs` | Формы параметров, сеть, Extra args, встроенная справка |
| `PolarTheme.cs`, `WorkspaceView.cs`, `EditorControls.cs` | Тема, компоновка, поля, списки и прокрутка |
| `DistroAppearance.cs` | PNG-каталог и отдельные визуальные настройки |
| `vm_backend.py` | JSON RPC и операции GUI |
| `vm.py`, `vm_console.py`, `vm_runtime.py` | CLI, QMP, идентификация VM и блокировки |
| `vm_network.py`, `vm_profiles.py` | Адаптеры и профили ускорения |
| `vm_editor.py`, `vm_storage.py`, `vm_snapshots.py` | Изменение параметров, безопасное удаление, снимки |
| `vm_doctor.py`, `vm_library.py`, `vm_style.py`, `vm_ui.py` | Диагностика и терминальный интерфейс |

Рабочий корень содержит `machines/`, `manager-settings.json`, `appearance.json`, `logs/`, `parameter-backups/` и пользовательские PNG. Пути к дискам/ISO задаются пользователем; копирование исходников не даёт права открывать или изменять эти файлы. Все такие данные исключены из Git.

Подготовка к GitHub изменила только копию для разработки: удалены личные стартовые примеры VM, пути сборки и тестов сделаны относительными, встроенный manifest приложения отделён от прежних папок установщика. Действующая установка не обновлялась. Исторические промежуточные исходники, отчёты, установщики и архивы не импортируются в проект.
