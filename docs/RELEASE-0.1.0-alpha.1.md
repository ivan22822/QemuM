# QemuM 0.1.0-alpha.1

Первая альфа для обычной работы с учебными виртуальными машинами.

## Скачать и начать

Скачай **QemuM-0.1.0-alpha.1-Setup.exe** из файлов этого выпуска.
Установщик создаёт отдельный экземпляр QemuM, скачивает Python и при отсутствии
QEMU предлагает его установку через запрос прав Windows. После установки открой
«QemuM Alpha» из меню «Пуск» и добавь свой ISO или диск.

Требования: Windows 10/11 x64, интернет при установке. Для WHPX требуется
настроенная аппаратная виртуализация. Если она недоступна, выбери профиль
«Авто» или TCG; TCG медленнее.

## Что входит

- Графическая библиотека VM, запуск и QMP-управление без лишних консолей.
- Параметры, сетевые адаптеры, Extra args со справкой, снимки qcow2 и VM Doctor.
- Кнопка «Помощь / отчёт»: выбор логов, параметров, диагностики, состояния QMP
  и PNG экрана VM; локальный ZIP и ссылка на GitHub Issues.
- Независимый загрузчик и кнопка «Обновления»: проверка GitHub Releases,
  контрольных сумм и состава пакета, сохранение предыдущей версии.

Ничего из отчёта не отправляется автоматически. Перед прикреплением ZIP к
публичному issue проверь содержимое. Скриншоты не маскируются.

## Проверки и ограничения

Проверены unit/GUI-сценарии, QMP и экспорт PNG на временной TCG-машине,
сборка пакета, запуск с закреплённым Python, разделение кода и данных,
проверки повреждённых архивов и отката. Проверена замена приложения на другой
EXE без Python через тот же протокол.

Установка QEMU с UAC на чистом другом компьютере и полноценная загрузка
гостевых ОС отдельно не проверены. EXE не подписан сертификатом издателя.
При прерванной первой установке выбери новую пустую папку.
Обновление требует закрыть менеджер и сохраняет работающие VM.
Откат возвращает код приложения; пользовательские данные не откатываются.
Python 3.14.8 и сборка QEMU 20260811 закреплены; обновление GUI их не заменяет.

ZIP приложения предназначен для обновлятора; для первой установки нужен EXE.
`SHA256SUMS.txt` содержит контрольные суммы файлов выпуска.
Разработка находится в отдельной ветке; выпуск не означает слияние в `main`.

Сообщить о проблеме: https://github.com/ivan22822/QemuM/issues
