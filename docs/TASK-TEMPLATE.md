# Карточка задачи

Агент заполняет кратко в существующем рабочем отчёте, не требует заполнения от пользователя.
Для мелкой правки отдельный файл не нужен.

- Результат: наблюдаемое поведение после изменения.
- Граница: конкретные пункты/подсистема; что осталось вне задачи.
- Приёмка: 1–5 проверяемых условий; существенные неоднозначности выяснить до кода.
- Код: точки входа и существующие компоненты для повторного использования.
- Проверки: релевантные профили + обязательные проверки перед коммитом.
- Решения: только новые значимые договорённости, причина одной строкой.
- Завершение: сделано / проверено / открыто; без галочек по предположению.
- Публикация: фактический запрос пользователя, не подразумевается задачей.

Для нового чата: обновить WORKING-CONTEXT; передать путь к отчёту, branch/HEAD,
dirty-изменения, следующий шаг, блокеры. Не переносить всю историю и журналы.
