## Асинхронность и ошибки — разделы 9, 22, 23, 26, 31

- [x] Открытие/отмена/поиск/наведение не изменяют диски и конфигурацию.
- [x] Существующие создание live и восстановление с запуском подключены через адаптер.
- [x] Будущие формы остаются доступными для просмотра; подтверждение отключено с причиной, если служба не поддерживает выбранный режим.
- [x] Передавать семантические значения, а не номера пунктов меню; сохранять исходные Unicode и переносы описания.
- [x] Получать реальные фазы и опциональные счётчики прогресса; не выдумывать проценты.
- [x] Отменять только при явном разрешении службы и известном ID операции.
- [x] Не закрывать окно и не прерывать worker во время операции.
- [x] При неподтверждённом результате блокировать повтор до обновления списка; не делать автоматический повтор.
- [x] Различать подтверждённую операцию с ошибкой обновления и неподтверждённую операцию.
- [x] Сохранять сведения о страховочной точке в сообщении результата, если они получены. Для старой службы явно отправлять к живому логу.
- [x] Не менять существующее поведение панели VM после остановки гостя.
